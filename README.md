# MARS FF — Официальные ссылки и донат

Официальная страница-переходник и приём донатов для стримера **MARS FF**.

## 🚀 О проекте
- **Графитовая темная тема**: глубокий графит, мягкие световые неоновые акценты (циан и янтарное пламя), плавные парящие искры на Canvas.
- **Интерактивный аватар**: анимированное неоново-синее дымное кольцо с ускорением при наведении.
- **Все изображения в формате SVG**: шапка канала, аватар, неоновые рамки и иконки.
- **Ссылки и донаты**:
  - 🟠 **DonationAlerts** — стримерские донаты с оповещениями
  - 🟢 **DonatePay** — донат на развитие канала
  - 🟡 **Т-Банк** — быстрый перевод и копирование номера карты в 1 клик
  - 🟢 **Сбербанк** — быстрый перевод и копирование номера карты в 1 клик
  - 🔴 **YouTube** — официальный канал, стримы и ролики
  - ✈️ **Telegram** — новости и общение
  - 🔵 **VK** — группа ВКонтакте
- **Адаптивность**: оптимизировано для смартфонов, планшетов и ПК.

## 🛠 Технологии
- **HTML5 & SVG** — чистая семантическая разметка и векторная графика
- **Vanilla CSS3** — Glassmorphism, CSS Animations, Flexbox, адаптивные стили
- **JavaScript** — анимация фоновых частиц на Canvas, Clipboard API, Ripple-эффекты
- **Node.js** — легковесный локальный веб-сервер с поддержкой Gzip-сжатия и кэширования
